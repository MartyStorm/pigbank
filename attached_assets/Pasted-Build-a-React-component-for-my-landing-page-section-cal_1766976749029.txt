Build a React component for my landing page section called “Payment Methods” with 5 cards: Credit Cards, ACH Transfers, Cryptocurrency, eChecks, Click to Pay.

Goal:
- Make the section communicate instantly with minimal reading.
- Each card is a “flip card”: the FRONT shows a big bold icon + short title. The BACK shows the detailed text (the same text I already have under each card today).
- DO NOT rely on hover-only. I want an automatic, one-time reveal so users don’t have to guess.

Interaction requirements:
1) Auto-flip ONCE when the section first enters the viewport (use IntersectionObserver).  
   - Flip each card sequentially with a stagger (e.g., 120ms between cards).
   - Keep cards flipped for ~1.2–1.8 seconds (pick something reasonable), then flip back.
   - This auto-flip should happen only one time per page load.

2) After the one-time auto-flip:
   - Desktop: hover flips to back; hover out flips to front.
   - Mobile/touch: tap toggles flip; tapping again flips back.
   - Keyboard accessibility: cards should be focusable; Enter/Space toggles flip.

- Cards should be white with rounded corners and soft shadow.
- Each icon should be large and bold (no thin strokes). Use inline SVG icons or a simple icon library (your choice), but keep them consistent and modern fintech style.
- Reduce reading: the section headline and subheadline should be short and high-impact.

Card content (exact):
